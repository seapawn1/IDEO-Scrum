**规则**：写插件命令/文档/角色内容前先查依据链——源材料原句（SG2020 / SGEP / d.school）、PO 初稿（`0f9d3e1` 等）、或明确标注的「作者设计」；**每条内容都要能指出出处**。无据内容会被直接拒收（PO 原话：「没有依据我是不可接受的」）。

**Why:** 2026-10-04 会话，PO 对命令来源连续追问（「designer 的来源是什么，依据是什么…sm 和 developer 我也没查到」），并因 Author's Additions 缺依据打回重写；依据链查清（初稿 commit + 修订决策 + 源材料）后才放行。同会话定案：SG 系材料可逐字抄录（CC BY-SA，署名入 ATTRIBUTION）；命令类组件不设文件头（规约例外已加）——但署名义务仍须由 ATTRIBUTION 登记承担。

**How to apply:** 新写/改写成块内容先自问「这句从哪来」；作者初稿来源写 commit 引用；自撰部分标注作者设计（或按批次决定只登记 ATTRIBUTION）。交付前可用脚本做逐字比对（抄录段 vs 源文件）作为证据。相关：[[frozen-approved-text]]
