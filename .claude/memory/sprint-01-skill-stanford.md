# Sprint 01（skill-stanford）蒸馏

> 源：全文 `Scrum/sprint-01-skill-stanford/SprintBacklog.md`（git 历史 `v1` tag 起可查）。

**增量**：design-kernel SKILL.md 融合 Stanford Design Guides，五模式达到 WHAT/WHY/HOW 三层；skill 更名 ideo-kernel → design-kernel；SKILL.md 重构为 Overview + Method Catalog 两层架构。

**教训**

1. **命名先定再做**：ideo-kernel→design-thinking→design-kernel 三换、IDEO-modes 三换——定名后再写内容。
2. **单个 L 级 PBI 占满 Sprint**：半途发现方向错误则全期已沉没；小 PBI 更有弹性。
3. **Sprint 事件脚手架全缺席**：Planning/Daily/Review 都没用，只剩 Backlog 与 Increment 两端——后续 Sprint 需真用事件。
4. **线性拆分有效**：拆源 → 摘抄 → 融合 → 重构（H-1→H-4），可回溯。
