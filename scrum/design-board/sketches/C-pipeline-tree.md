从上往下流：根是产品，往下分出正在跑的几条线（冲刺、设计），每条线自己一排五个阶段节点；没在跑的条目和已收官的冲刺折成几个带数字的节点。点任何一个节点，它的内容从底下（竖屏、手机）或右边（电脑）滑出来。

## 结构和节点

- 根：产品（点开：产品陈述原文、Product Goal 原文、九步架构图的概括）。
- 第二层：正在跑的线，一条一组，颜色分线（冲刺一种、设计一种）；冲刺里开的设计挂在冲刺下面。
- 每组里：一排五个阶段节点（实心已过、亮的是现在、空心未到）；组里的条目是小标签，带状态点；工作块折成「9/15 ✓」，点开才列。
- 折叠节点：「待选」「以后」「已收官」各一个，只显示数字，点开展开成列表。
- 点任何节点出内容：几行概括（目标、Now 原文、做完的块），加一个「打开日志」的链接；不搬日志正文。

## 几条线并行

一条线一组，横着并排（竖屏放不下就上下排）；每组只有一个亮点：当前阶段。瞄一眼，看亮点落在哪一格就知道每条线走到哪。

## 电脑全屏与手机 375 宽

- 电脑全屏：从左往右流，像 GitHub Actions 的图：产品在最左，线一行一组往右排；内容面板在右侧。
- 手机：单列，每条线一张窄卡、一排小阶段点；点开内容占满屏，返回回到图。

## 条目很少、白纸

只有根节点和 Product Goal，下面一个虚线的空组：「第一个冲刺会出现在这里」；折叠节点数字为 0 时不显示。

甲、乙站在「流程」上画（九步是路，线是车）；丙站在「结构」上画（产品分出线，线里有阶段和条目），九步架构图收进根节点里。可以合：丙做骨架，每条线的那一排阶段节点借甲的「实心、亮、空心」画法；视觉借乙的克制。
