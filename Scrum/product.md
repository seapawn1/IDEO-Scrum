## Product

**IDEO-Scrum** 是一个 Claude Code marketplace 插件，将 Design Thinking（设计思维）和 Scrum Sprint（敏捷冲刺）两套方法论集成到 Claude Code 中，通过技能（skills）、参考文档（references）和角色代理（agents）提供结构化的方法论引导和流程框架。

**Product Vision**：让 Claude Code 成为一个随身的设计思维与敏捷教练——有方法论需求的人打开 Claude Code 调用 IDEO-Scrum，就能获得结构化、忠于原文、可操作的方法论引导。
